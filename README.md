# neural-inference-contract

Автоматная модель смарт-контракта оплаты запросов к нейросетевому сервису.

**Этап:** базовая модель контракта и консольные сценарии.

## Идея проекта

Пользователь резервирует средства для одного запроса к языковой модели. Провайдер принимает запрос, выполняет его вне блокчейна и публикует квитанцию о результате. Подтверждение пользователя или решение арбитра определяет оплату; сроки и отдельные действия по их истечении позволяют обработать отказ участников.

В проекте я исследую, как действия пользователя, провайдера и арбитра, а также задержки влияют на расчёты. Цель — определить условия завершения оплаты и найти сценарии, при которых средства остаются заблокированными.

## Контракт

- Один пользователь, один провайдер, заранее выбранный арбитр и один запрос с уникальным идентификатором.
- Согласованы модель, цена учётной единицы и максимальный объём запроса. В первой версии единица — токен с единой ценой для входа и выхода.
- Пользователь резервирует максимальную стоимость; при оплате провайдер получает согласованную фактическую стоимость, остаток возвращается пользователю.
- Провайдер публикует подписанную квитанцию с идентификатором запроса, хешами запроса и ответа, объёмом и стоимостью.
- Пользователь подтверждает результат или открывает спор. Отсутствие подтверждения после срока позволяет отдельным действием передать запрос в спор.
- Арбитр выбирает оплату либо полный возврат. При истечении срока спора отдельное действие позволяет вернуть средства пользователю.

Авторство квитанции проверяется по подписи провайдера. Пользователь принимает результат или передаёт спор арбитру. Для завершения расчётов после истечения срока участник вызывает отдельную операцию контракта.

## Возможности

- Семь этапов контракта и чистая функция перехода: состояние и событие на входе, новое состояние и результат обработки на выходе.
- Проверка ролей, суммы резерва, соответствия квитанции и сроков.
- Оплата, полный возврат, арбитраж и отдельные действия после истечения срока.
- Неизменяемые состояния и защита от повторного начисления при повторных событиях.
- Бинарные выходы Мура и Мили, журнал переходов и распределение средств на каждом шаге.
- Десять сценариев и тесты денежных инвариантов, прав участников и граничных условий.

Правила контракта, математическая модель и этапы разработки описаны в [отчёте](docs/report.md).

## Реализация на C#

Приложение написано на **C# / .NET 10**. Правила контракта находятся в `Model`, последовательности событий и их исполнение — в `Scenarios`. Консольный интерфейс выводит трассу выбранного сценария. Генерация ответа нейросети представляется событием среды. Расчёты выполняются в условных денежных единицах.

В начальной конфигурации цена токена равна `1`, лимит — `2`, резерв — `2`. Подписи и идентификаторы представлены признаками соответствия; сетевые запросы и реальные платежи не выполняются.

## Запуск

Требуется .NET 10 SDK. Команды выполняются из корня репозитория:

```powershell
dotnet build NeuralInferenceContract.slnx
dotnet run --project src/NeuralInferenceContract -- success
```

Список сценариев и выполнение всех сценариев:

```powershell
dotnet run --project src/NeuralInferenceContract -- --list
dotnet run --project src/NeuralInferenceContract -- all
```

Без аргументов выполняются все сценарии. `--help` выводит справку. Неизвестное имя сценария или лишние аргументы возвращают код завершения `2`.

## Сценарии

| Имя | Содержание |
| --- | --- |
| `success` | Подтверждение ответа, оплата и возврат остатка |
| `full-cost` | Оплата всего зарезервированного объёма |
| `provider-no-accept` | Возврат после истечения срока принятия |
| `provider-no-result` | Возврат при отсутствии квитанции |
| `user-silent` | Открытие спора по сроку и оплата по вердикту |
| `dispute-pay` | Спор с решением об оплате |
| `dispute-refund` | Спор с решением о возврате |
| `arbiter-offline` | Возврат после истечения срока арбитража |
| `no-initiator` | Ожидание с заблокированным резервом после срока |
| `replay-and-invalid` | Неверные роли, квитанции и повторные сообщения |

## Тесты

```powershell
dotnet test --solution NeuralInferenceContract.slnx
```

Тесты используют xUnit v3 и Microsoft.Testing.Platform. Они проверяют денежный учёт, права участников, квитанции, сроки и повторные события. Отдельная проверка обходит достижимые состояния конфигурации `p=1, U=2` по конечному тестовому алфавиту.

В GitHub Actions при открытии PR и изменениях в `main` запускаются общие workflow проверки форматирования и тестирования из `PANiXiDA-Infrastructure/ci-cd`. Тестовый workflow собирает проект с анализаторами, публикует результаты тестов и отчёт о покрытии. Решение хранится в формате `.slnx`.

Проверка форматирования локально:

```powershell
dotnet format NeuralInferenceContract.slnx --verify-no-changes --severity warn
```
