# neural-inference-contract

Автоматная модель смарт-контракта оплаты запросов к нейросетевому сервису.

**Этап:** проектирование модели.

## Идея проекта

Пользователь резервирует средства для одного запроса к языковой модели. Провайдер принимает запрос, выполняет его вне блокчейна и публикует квитанцию о результате. Подтверждение пользователя или решение арбитра определяет оплату; сроки и отдельные действия по их истечении позволяют обработать отказ участников.

В проекте я исследую, как действия пользователя, провайдера и арбитра, а также задержки влияют на расчёты. Цель — определить условия завершения оплаты и найти сценарии, при которых средства остаются заблокированными.

## Контракт

- Один пользователь, один провайдер, заранее выбранный арбитр и один запрос с уникальным идентификатором.
- Согласованы модель, цена учётной единицы и максимальный объём запроса. В первой версии единица — токен с единой ценой для входа и выхода.
- Пользователь резервирует максимальную стоимость; при оплате провайдер получает согласованную фактическую стоимость, остаток возвращается пользователю.
- Провайдер публикует подписанную квитанцию с идентификатором запроса, хешами запроса и ответа, объёмом и стоимостью.
- Пользователь подтверждает результат или открывает спор. Отсутствие подтверждения после срока позволяет отдельным действием передать запрос в спор.
- Арбитр выбирает оплату либо полный возврат. При истечении срока спора отдельное действие позволяет вернуть средства пользователю.

Авторство квитанции проверяется по подписи провайдера. Пользователь принимает результат или передаёт спор арбитру. Для завершения расчётов после истечения срока участник вызывает отдельную операцию контракта.

## План реализации

1. Детерминированный автомат контракта и его представления Мура и Мили.
2. Управляющие автоматы среды для успешного выполнения, отказов, задержек и повторных событий.
3. Сплетение автоматов контракта и среды.
4. Поиск достижимых состояний, замкнутых компонент и путей к критическому поведению.
5. Геометрические образы входных и выходных слов с маркировкой найденных компонент.
6. Воспроизводимые сценарии, проверка денежных инвариантов и экспорт результатов для отчёта.

Правила контракта, математическая модель и этапы разработки описаны в [отчёте](docs/report.md).

## Реализация на C#

Для реализации выбраны **C# и .NET 10**. Консольное приложение будет моделировать правила контракта, строить графы и анализировать их. Генерация ответа нейросети представляется событием среды. Расчёты выполняются в условных денежных единицах.

Форматы экспорта: CSV для таблиц и траекторий, Mermaid для графов переходов, SVG для геометрических изображений.
